# LHS-1 and LMS-1 ideal recipes

A single static page: ideal mineral recipes for lunar highlands (LHS-1) and lunar mare (LMS-1) simulants, predicted from lunar-sample chemistry with a model trained on 180 samples with measured modes,
compared with the public LHS-1 and LMS-1 fact sheets. Open `index.html` or the GitHub Pages site for this repository.

Chemistry: Astromat, T., 2025. Astromat Synthesis Compilation: Lunar samples v.1 February 2025, Version 1.0. Interdisciplinary Earth Data Alliance (IEDA). https://doi.org/10.60520/IEDA/113696 (CC-BY-4.0).
Modes: Taylor et al. (2019, doi:10.1016/j.gca.2019.07.046; Zenodo 10.5281/zenodo.5899696), Astromat point counts, Lunar Sample Compendium (C. Meyer, NASA JSC).
Modes in the training data are of size fractions or thin sections, not bulk soil.
